2. Business Rule Constraints Enforced in Engine

• Compound Unique Index on registrations: { student: 1, event: 1 } blocks double registration at the MongoDB engine layer.
• Unique Index on attendances.registration: Enforces that each registration can only be checked in once, returning 409 on re-scans.
• Case-Insensitive Alphanumeric Indexing: Allows Fast Pass IDs to be scanned in uppercase or lowercase without query degradation.
